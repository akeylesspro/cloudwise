**** Presentation ****
This is my server that should handle automatic charging (in addition to other things that we will not focus on right now)
I have the collections "nx-charge-state", "nx-charge-sessions"
which are responsible for managing this
The nx-charge-state collection contains the current state of a vehicle (one-to-one)
The nx-charge-sessions collection is responsible for saving all sessions of the vehicle (one-to-many)
I listen to the following events in the nx-charge-state collection and follow the following diagram:
** Charging start **
I expect to receive an add-on event in nx-charge-state and then start a charging session
Before I start a charging session I do 3 things
1 I make sure that the vehicle has enough credit to start charging if not then I throw an error and update the nx-charge-state collection with the error
2 I make sure that there are chargers with a status of waiting to charge in the area where I received the event, if there are none, then I Throws an error and updates the nx-charge-state collection with an error.
3 I get the closest charge to the time I received the event. If I don't find such an event, then I throw an error and update the nx-charge-state collection with an error.
4 I send a start charge in the API and change the status of nx-charge-state to charging. If that doesn't work, then I throw an error and update the nx-charge-state collection with an error.
** Charge exists **
When I get a charge event in nx-charge-state
I start a timer that does a few things:
1 I get the status of the current session in the API and check that it hasn't expired. If so, I take care of updating the collections.

2 I check that there is enough credit to continue charging. If not, I throw an error and update the nx-charge-state collection with an error.
** Error **
If there is any error, I update the relevant code
