**** Presentation ****
This is my server that should handle automatic charging of vehicles and credit charging.
I have the collections "nx-charge-state", "nx-charge-sessions"
which are responsible for managing this.
The nx-charge-state collection contains the current state of the vehicle (one-to-one)
The nx-charge-sessions collection is responsible for storing all the sessions of the vehicle (one-to-many)
I listen to the following events in the nx-charge-state collection and follow the following diagram:

** Charging started **
I expect to receive another event in nx-charge-state and then start a charging session
Before I start a charging session I do 3 things:

1 I make sure that the vehicle has enough credit to start charging if not then I throw an error and update the nx-charge-state collection with the error

2 I make sure that there are chargers with a status of waiting to charge in the area where I received the event, if there are none, I throw an error and update the nx-charge-state collection with an error.

3 I get the closest charging to the time I received the event. If I don't find such an event, I throw an error and update the nx-charge-state collection with an error.

After I have the data I do a few more things:

1 I send an initial charge in the API and change the status of nx-charge-state to charging. If that doesn't work, I throw an error and update the nx-charge-state collection with an error.
2 I update the nx-charge-state and nx-charge-sessions collections that I started charging
3 Print a log and send an SMS (only for a specific vehicle)

** Active charging session**
When I receive a charging event in nx-charge-state
I start a timer that does a few things:

1 I get the status of the current session in the API and check that it hasn't expired. If so, I make sure to update the collections.

2 I check that there is enough credit to continue charging. If not, I end the session.

** Error **
If there is any error, I update the relevant code

*** End session ***

At the end of a session, I do a few things:

1 Make sure that the session is indeed valid and correct

2 Send an API command to end the session

3 Make sure to charge the session

4 Update cookies

5 Collect CDR and complete the charging of the entire operation
